# Gradio 远程访问说明

## 方法一：SSH 端口转发（推荐，最安全）

### 步骤：

1. **在本地终端执行 SSH 端口转发命令**：
   ```bash
   ssh -p 42050 -L 7860:localhost:7860 root@connect.westd.seetacloud.com
   ```
   
   **说明**：
   - `-p 42050`: 指定 SSH 端口为 42050
   - `-L 7860:localhost:7860`: 将本地 7860 端口转发到服务器的 7860 端口
   - `root@connect.westd.seetacloud.com`: 你的服务器地址
   
   如果使用其他服务器，格式为：
   ```bash
   ssh -p <SSH端口> -L 7860:localhost:7860 用户名@服务器地址
   ```

2. **保持 SSH 连接打开**，在服务器上启动 Gradio：
   ```bash
   cd /root/autodl-tmp/dit/1Prompt1Story
   python resource/gradio_story_generator.py
   ```

3. **在本地浏览器访问**：
   ```
   http://localhost:7860
   ```

### 优点：
- ✅ 安全（通过 SSH 加密）
- ✅ 不需要修改防火墙
- ✅ 不需要公网 IP
- ✅ 适合内网环境

---

## 方法二：直接访问服务器 IP（需要防火墙配置）

### 步骤：

1. **确保服务器防火墙允许端口访问**：
   ```bash
   # Ubuntu/Debian
   sudo ufw allow 7860
   
   # CentOS/RHEL
   sudo firewall-cmd --add-port=7860/tcp --permanent
   sudo firewall-cmd --reload
   ```

2. **启动 Gradio**（脚本已默认监听所有接口）：
   ```bash
   python resource/gradio_story_generator.py
   ```

3. **在浏览器访问**：
   ```
   http://服务器IP:7860
   ```

### 优点：
- ✅ 直接访问，无需 SSH 连接
- ✅ 可以分享给其他人

### 缺点：
- ⚠️ 需要配置防火墙
- ⚠️ 需要服务器有公网 IP 或在内网可访问

---

## 方法三：使用 Gradio 公共链接（最简单，但需要网络）

### 步骤：

1. **启动时添加 `--share` 参数**：
   ```bash
   python resource/gradio_story_generator.py --share
   ```

2. **Gradio 会自动生成一个公共链接**，类似：
   ```
   https://xxxxx.gradio.live
   ```

3. **在任何地方访问这个链接**（包括手机）

### 优点：
- ✅ 最简单，无需配置
- ✅ 可以分享给任何人
- ✅ 支持 HTTPS

### 缺点：
- ⚠️ 需要稳定的网络连接
- ⚠️ 链接有时效性（通常几小时）
- ⚠️ 数据会经过 Gradio 服务器

## 方法四：自定义端口和主机

### 使用自定义端口：

```bash
# 使用 8080 端口
python resource/gradio_story_generator.py --port 8080

# 然后 SSH 转发时使用相同端口
ssh -L 8080:localhost:8080 用户名@服务器IP
```

### 只监听本地接口（更安全）：

```bash
# 只允许本地访问
python resource/gradio_story_generator.py --host 127.0.0.1 --port 7860

# 必须使用 SSH 端口转发才能访问
ssh -L 7860:localhost:7860 用户名@服务器IP
```

## 常见问题

### Q1: 连接被拒绝？
- 检查服务器防火墙是否允许端口访问
- 检查 `server_name` 是否设置为 `0.0.0.0`
- 检查端口是否被其他程序占用

### Q2: SSH 端口转发失败？
- 确保 SSH 连接正常
- 检查本地端口 7860 是否被占用
- 尝试使用其他端口：`ssh -L 8080:localhost:7860 ...`

### Q3: 如何查看服务器 IP？
```bash
# 查看公网 IP
curl ifconfig.me

# 查看内网 IP
ip addr show
# 或
ifconfig
```

### Q4: 如何检查端口是否在监听？
```bash
# 检查端口是否被占用
netstat -tuln | grep 7860
# 或
ss -tuln | grep 7860
```

## 推荐配置

**开发/测试环境**：使用方法一（SSH 端口转发）
- 安全、简单、无需额外配置

**生产环境**：使用方法二（直接访问）+ HTTPS
- 需要配置反向代理（如 Nginx）和 SSL 证书

**临时演示**：使用方法三（Gradio 公共链接）
- 快速分享，适合临时演示
